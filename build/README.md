# 🎮 Flappy Sudheer - Little Hearts Edition (Web App)

A custom web-based Flappy Bird game featuring **Sudheer** from the viral *Little Hearts* series flying through stacks of college textbooks to win Katyayani's heart!

---

## 🌟 Features

- **Character**: Sudheer (`assests/sudheer.png`) with dynamic rotation and comic flap animations.
- **Background Music**: *"Little Hearts - Katyayani Nanu Love Cheyavey Full Song"* plays continuously during gameplay.
- **Game Over Sound**: Custom loss sound effect (`assests/gameover.mp3`) triggers immediately on collision.
- **Obstacles**: Realistic stacks of college textbooks (matching the reference video reel).
- **Parallax Campus Background**: Scenic college campus backdrop with sunset clouds.
- **Score System & Medals**:
  - Live Flappy Bird-style outline score counter.
  - High score saved automatically in `localStorage`.
  - Humorous Telugu post-game performance medals & quotes.
- **Audio Controls**: Mute / Unmute toggle button (or press `M`).
- **Responsive Layout**: Seamless mobile-friendly reel frame on desktop or full screen on phones/tablets.

---

## 🕹️ Controls

| Action | Control |
|---|---|
| **Flap / Jump** | `SPACE` or `Up Arrow` (Keyboard), or `Click` / `Tap` anywhere |
| **Mute / Unmute** | `M` key or click the 🔊 button |
| **Restart Game** | `SPACE` or `Click / Tap Play Again` |
| **Toggle Fullscreen** | Click the ⛶ button in the top right |

---

## 🚀 How to Run on Localhost

Run the built-in Node.js server:

```bash
npm start
```
or
```bash
node server.js
```

Then open your browser and navigate to:
👉 **[http://localhost:3000](http://localhost:3000)**

Enjoy the game! 🚀
